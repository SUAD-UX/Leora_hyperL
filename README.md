# LEORA — Your Risk, at a Glance

**See your risk before it becomes a problem.**

A minimal, read-only dashboard for tracking Hyperliquid positions, PnL, funding rates, and liquidation distance in real-time.

## Features

- 📊 **Position Tracking** — View all open positions with size, entry price, and current PnL
- ⚠️ **Liquidation Distance** — Instant clarity on how close you are to liquidation
- 💰 **Funding Rates** — Monitor ongoing funding costs
- 🔒 **Read-Only** — No keys, no signing. Watch any wallet or connect your own
- ⚡ **Live Updates** — Data refreshes every few seconds

## Get Started

Visit **[leora-hyper-l.vercel.app](https://leora-hyper-l.vercel.app)** and:
- Paste any Hyperliquid wallet address, or
- Connect your wallet to view your positions

## Tech Stack

- **Vite** + React 18
- **Hyperliquid Info API** (read-only)
- **Tailwind CSS** + Framer Motion

## Local Development

```bash
npm install
npm run dev
```

Runs at `http://localhost:5173`
